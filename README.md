# Las Colombianitas

Landing page comercial de **Las Colombianitas** (arepas y empanadas) para tiendas latinas, restaurantes y distribuidores en Florida.

- `index.html` — Propuesta A (verde y dorado)
- `propuesta-b.html` — Propuesta B (amarillo maíz y azul)
- `propuesta-c.html` — Propuesta C (inspirada en las chivas)

## Antes de publicar en serio
Edita el bloque `SITE_CONFIG` al inicio de cada página: correo, teléfono, WhatsApp, Instagram, endpoint del formulario (Formspree, Getform o `/api/lead` en Vercel), fotos reales y datos comerciales.
